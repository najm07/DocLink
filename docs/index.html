Built for real offices

Zero-config discovery

mDNS finds every DocLink PC on your network automatically. The Add dialog lists live PCs — click one, no IPs to type, no ports to forward.

Trust you control

Every PC has a DocLink ID bound to a cryptographic identity. Pairing is an explicit request the owner approves — and revokes at any time.

Scoped grants

Share the whole folder or just one file with specific PCs. Access is enforced server-side on every request.

Read-only, always

Peers can only browse and download. They can never modify, delete, or upload to your PC. No inbound writes, ever.

Signature-authenticated

Every request is signed (ed25519) and timestamped. The web UI talks only to a localhost admin plane; the LAN sees only the locked-down data plane.

No cloud, no accounts

Your files never leave the LAN. DocLink has no server to join, no telemetry, nothing to configure beyond one firewall prompt.

Up and sharing in a minute

  1. Run it. Unzip and launch doclink-win.exe on both PCs. Accept the one-time firewall prompt.
  2. Add. On your PC press +, pick the other PC from the discovered list (or paste its DocLink ID) and give it a name.
  3. Approve. On the other PC, accept the request — optionally scoped to a single file. Browse and download.
